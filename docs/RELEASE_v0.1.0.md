# 黑火守望 v0.1.0

首个带统一版本标识的公开测试版，发布于 2026-10-18。

## 本次变化

- 新增 `bk2/version.py` 作为程序名称、版本、标签和发布渠道的唯一代码定义。
- 窗口标题和控制台顶部显示“黑火守望 v0.1.0”。
- `python -m bk2 --version` 显示版本并退出，不连接游戏或加载挂机设置。
- `check` 输出以及运行失败、界面识别两类诊断新增 `application` 信息；原报告格式版本保留，历史诊断不改写。
- Git 标签使用 v0.1.0，CI 核对标签与代码一致。后续修复递增补丁版本，新增功能递增次版本；稳定标准达成后再使用 v1.0.0。

## 验证

- 实际 BK2 副本与发布副本的 8 个相关代码/测试文件按换行归一后内容一致。
- BK2 的 5 项新增版本集成测试全部通过，包括隐藏窗口构建、CLI 退出和两类诊断落盘。
- 发布副本完整离线回归共 288 项：191 项通过，97 项因未分发本地截图而跳过，0 失败，0 错误。跳过项不计为通过。
- 实际 BK2 的 `--version` 输出“黑火守望 v0.1.0”；`check` 核验游戏文件哈希、模板和依赖通过。
- 本次维护未向游戏发送输入。上述验证不代表新一轮实机挂机验收。

本机挂机设置保持原值。维护过程未写入冷却或领取计时，正在运行的旧进程产生的正常计时更新予以保留。更新后重启应用才能加载新版本显示。
