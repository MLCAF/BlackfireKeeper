# 禁域挂机：黄金古国

连接游戏后切换到“禁域 · 黄金古国”，设置探索次数和体力下限，再点击“开始禁域”。可从主城、底部导航、黄金古国详情或探索页面开始。默认 10 次、体力下限 3；只有点击“保存禁域设置”才会写入独立的 config/runtime/forbidden_options.json，不覆盖地下城计划。

探索消耗 3 点体力。遇敌时开启自动战斗，确认经验和战利品领取后返回探索页；宝箱事件只免费打开一个，识别“已获得”后关闭。宝箱数量和位置变化时重新识别，不点击钻石价格，也不依赖固定宝箱数量。

禁域使用前台点击，会移动鼠标并将游戏置前；运行期间保持游戏可见，不要手动操作鼠标。此模式独立选择前台输入，不改动地下城已保存的输入设置。后台消息点击在本机地图、详情页未获响应，因此主界面禁域流程不使用它。

本模式不与地下城同时运行，期间不执行原有定时体力/钻石领取。体力低于下限、完成次数后停止；战败、未知页面或动作结果超时会停止并保存诊断。F8 随时停止。一次探索或免费开箱请求只提交一次，不能确认结果时不重复点击。

地图名称是“黄金古国”。其他禁域地图尚未支持。新规则保持 0.95 匹配阈值及亮度/对比度保护，截图仍使用 720 短边统一坐标。原生 1600×826 客户区已进行本机导航与探索验证；提供视频的标准画面做了回放，未宣称其他尺寸、所有队伍或长期挂机均通过实测。战斗能否获胜取决于游戏中的实际队伍状态；战败不会自动重试。

便携版和源码版使用同一流程、模板与版本。升级时保留原目录的 config/dungeon_plan.json 和 config/runtime/；不将本机设置、冷却记录、完整玩家截图或视频装入发布包。
