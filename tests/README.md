# 测试范围

从仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -X utf8 -m unittest discover -s tests -t . -v
```

单元测试使用模拟内存、模拟时钟和模拟输入，覆盖状态读取、冷却、体力阈值、定时领取、调度、放弃副本后继续和诊断保存。不会刷副本或领取奖励。

截图回放代码仍保留，但 `tests/fixtures/` 中的玩家完整截图不公开。依赖这些素材的测试类在目录不存在时明确跳过；需要完整原始素材后才能启用，只有部分素材仍会报缺失错误。不要用空目录解除跳过。

`migration_manifest.json` 记录公开版本中移植文件的相对路径和内容哈希，移除了本机绝对路径；文本按 LF 换行计算哈希，兼容 Windows 的 Git 换行转换。`legacy_diamonds.json` 是旧人工确认流程的测试配置，用于验证不会把一次点击误记为领取成功，不用于正式挂机。

公开测试通过不能替代实际游戏验证，也不能等同于本地包含历史截图的完整回归结果。
